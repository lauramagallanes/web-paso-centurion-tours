Versión con comandos curl para evitar problemas CORS

⚠️ Problema CORS Detectado

Los navegadores bloquean requests desde file:// a https://. Usa los comandos curl que se muestran abajo para probar los endpoints desde terminal.

📋 Endpoints Básicos

Estos deberían funcionar:

GET /basic
GET /simple
GET /ping

🔐 Endpoints de Autenticación

Estos fallarán hasta que subas el JAR:

GET /auth/info
POST /auth/login
POST /auth/signup

💻 Comandos de Terminal

Copia y pega estos comandos en tu terminal:

Probar todos los endpoints básicos:
./test-endpoints.sh
Probar endpoint específico:
curl -X GET "https://53dmek6dqk.execute-api.us-east-1.amazonaws.com/basic"
Ver logs de Lambda:
aws logs describe-log-streams --log-group-name "/aws/lambda/tinambu-tours-backend-dev" --order-by LastEventTime --descending --max-items 1
